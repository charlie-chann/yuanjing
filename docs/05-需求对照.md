# 需求逐条对照（2026-11-14）

对照原始 PRD 逐条看。「做了」指在 iPhone 16 Pro 模拟器里点过、能用；「占位」指界面和流程有了，但背后是本地规则或示例数据，接上真实服务才算完。

## 后端（2026-11-14 加上）

后端在 `server/`（FastAPI，本地 SQLite，见 server/README.md）。应用以服务器为准：金币、商城、会员、广场、好友都必须在线；许愿、终点密码、肯定语、宠物、资料没网时先记在本机，连上后补发。接后端之前存在手机上的数据会在第一次登录时自动搬上去。
「AI 生成」：服务器配了大模型就用模型，否则用模板（服务器 `app/ai/templates.py`，应用里 `lib/app/muse.dart` 是没网时的备用）。广场上的示例用户和动态现在在服务器的数据库里。
还没做：手机号或 Apple 登录（现在是设备号免注册，换手机带不走）、苹果内购、云端文本和图片审核、上线部署。
