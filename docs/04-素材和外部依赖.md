## 语音怎么重新生成

```bash
cd tools/tts
.venv/bin/python generate_guides.py                      # 只生成还没有的
.venv/bin/python generate_guides.py --force              # 全部重生成
.venv/bin/python generate_guides.py --only mood_2 --take 3   # 单句换一版
```

语气由 `generate_guides.py` 里的 `STYLE` 那句话控制，音色由 `SPEAKER` 控制。改引导语文字时，这里和界面上的字要一起改：许愿的在 `lib/features/wish/wish_category.dart`，释放仪式的全部引导语和肯定语在 `lib/features/release/release_data.dart`。冥想的在 `lib/features/heal/heal_data.dart`，成品肯定语在 `lib/features/shop/shop_data.dart`。

生成完先用两个脚本筛一遍再听：模型偶尔会多念、漏念或拖长。

```bash
.venv/bin/python check_guides.py          # 按语速找念得太长或太短的
.venv/bin/python asr_check.py med_ -v     # 用本地语音识别把语音转回文字和原文对照（第一次会下载 Whisper small）
```

目前已知两句拖得偏长、换了四版都没变短，先保留：`med_vision_2`（约 12 秒）、`med_calm_2`（约 11 秒，念「数到四、数到六」时停顿多，可能是故意的节奏）。

## 声音怎么重新生成

```bash
cd tools/audio
../tts/.venv/bin/python generate_audio.py                       # 全部重生成
../tts/.venv/bin/python generate_audio.py amb_mood sfx_coin_1   # 只生成指定的
```

每个声音是脚本里的一个函数，函数开头的一句话写了它想要的听感。改完重新生成，再重新编译应用。
