# 技术架构

## 分工

```
┌──────────────────────────── Flutter（Dart）────────────────────────────┐
│ 页面、导航、状态、文案、网络和数据、会员和金币、界面微动效（Rive）          │
│ lib/features/<功能>/…                                                    │
└───────────────┬──────────────────────────────────────┬─────────────────┘
                │ PlatformView（把原生画面嵌进页面）      │ MethodChannel（遥控和回调）
┌───────────────┴──────────────────────────────────────┴─────────────────┐
│ packages/yuanjing_engine      原生引擎（iOS：Swift）                      │
│ ├ 仪式舞台 StageView    Metal 全屏着色器：七场许愿仪式（已做）              │
│ ├ 房间 RoomView         RealityKit：房间、形象、宠物（已做，素材是占位）    │
│ ├ 成片 FilmView         AVFoundation：愿景板的循环成片（待做）              │
│ ├ 触感 Haptics          CoreHaptics：和画面节点对齐（已做）                │
│ └ 声音 Voice、AudioDirector  引导语、环境音、音效（已做，素材是合成的）    │
└─────────────────────────────────────────────────────────────────────────┘
```

原则：凡是「每帧都在动、要质感」的画面都在原生层渲染，Flutter 不参与逐帧绘制；Flutter 只说「演哪一场」「开始」，原生层说「演完了」。这样动画不受 Dart 垃圾回收和界面重建影响。

## 仪式舞台的协议

视图类型 `yuanjing/stage`，创建参数 `{scene}`。每个视图一个通道 `yuanjing/stage_<视图编号>`：

| 方向 | 方法 | 参数 | 说明 |
|---|---|---|---|
| Flutter 到原生 | `setScene` | `scene`：许愿七场 wealth、career、looks、health、mood、life、pet；释放五场 release_pool、release_balloon、release_arrow、release_potion、release_deep | 暗下去，换场景，再亮起来 |
| Flutter 到原生 | `play` | `duration`（秒，可选，只对释放五场有效） | 开始仪式，返回时长（秒） |
| Flutter 到原生 | `stop` | 无 | 中途结束，不发 `done`，画面暗一下回到开始前 |
| Flutter 到原生 | `reset` | 无 | 清掉放完之后的余韵，回到开始前（再放一次时用） |
| Flutter 到原生 | `setTouch` | `x`、`y`，-1 到 1 | 轻微视差，将来接陀螺仪 |
| 原生到 Flutter | `done` | 无 | 仪式播完 |

每个场景有两种待机状态：没许愿之前，和许过之后的「余韵」。余韵由原生层记住，切走再回来还在。

## 加一场新仪式要改哪里

1. `shaders/stage.metal`：写一个 `sceneXxx` 函数，在 `stage_fragment` 里加一个分支。
2. `StageView.swift` 的 `StageScene`：加枚举值、时长、触感节点。
3. `tool/preview/main.swift` 的 `durations`：加时长。
4. `lib/features/wish/wish_category.dart`：加分类和三句引导语。
5. 跑 `tool/embed_shaders.sh`，再用 `render_preview` 出图检查。

许愿七场的时间轴节点（第几秒落水、第几秒日出）写死在着色器里，改时长时要一起改。

释放五场不一样：着色器只看进度（0 到 1），`StageView.swift` 里的音效和触感节点也按进度写，时长由 Flutter 在 `play` 时指定，所以轻量和深度两档共用同一套画面。纸船那两场和锁链是光线步进的真三维，热气球和魔药是画出来的立体感。

释放流程分五段（呼吸、放松、看见、释放、安住），再加肯定语跟念。每段多长、两档各有哪几段，都是 `lib/features/release/release_data.dart` 里的常量和 `lightRelease`、`deepRelease` 两个配置，`totalLength` 算总时长，测试会核对它落在需求的范围里；流程本身在 `release_page.dart`，一段接一段用定时器串起来。只有「释放」那一段调原生的 `play`，其余几段原生层都是待机画面。后三句引导语出现在进度的哪里，写在每种方式的 `at` 里，要和着色器里的节点对上；留白提示由 `holdTimes` 自动夹在空档里。调试版长按开始按钮可以跳过呼吸、14 秒看完整场。

## 仪式舞台的渲染管线

`StagePipeline.swift` 只依赖 Metal，iOS 视图和 Mac 上的预览工具共用。每帧四步：

1. 场景画进一张高动态范围的贴图（亮度可以超过 1，比如日面、金币的高光）。
2. 取出亮部，逐级缩小五次。
3. 再逐级放大叠回去，得到柔和的辉光。
4. 合成：场景加辉光，过色调映射、暗角、轻微的边缘色散和胶片颗粒。

辉光的阈值和强度是 `StagePipeline` 上的两个属性。仪式进行时镜头会缓缓推近约 7%，结束前回到原位。

调试版里长按「许下心愿」可以不写心愿直接预览当前这一场仪式，不记心愿、不加金币；正式版没有这个入口。

## 声音

三层，各管各的：

| 层 | 文件 | 行为 |
|---|---|---|
| 环境音 | `assets/audio/amb_<场景>.m4a` | 24 秒无缝循环。七个分类各一条，房间一条。换场景时两条轨道交叉淡入淡出 |
| 音效 | `assets/audio/sfx_<名字>.m4a` | 仪式里按时间点触发（`StageView.swift` 里每场的 `sounds`），和触感用同一个时钟；界面点击也用它 |
| 引导语 | `assets/voice/<场景>_<1..3>.m4a` | 说话的几秒里环境音自动压到四成，说完恢复 |

每场仪式都以同一个完成音收尾。素材读不到时静默跳过并打一行日志 `[yuanjing] 声音素材读不到`。

Dart 一侧：`YuanjingAudio.bed('room')` 换环境音，`YuanjingAudio.sfx('tap')` 播音效。

## 渲染上的取舍

- 财富这一场是光线步进（金币是数学定义的实体，逐像素求交），按 1.5 倍像素密度渲染；其余六场是解析式的，按 2 倍渲染。
- 金币上的「心想事成」是启动时用系统字体画的一张高度图，着色器用它做浮雕法线。
- 着色器以字符串形式在运行时编译，不依赖打包方式（Flutter 现在默认用 Swift Package Manager 集成插件）。编译失败会打日志 `[yuanjing] 着色器编译失败`，画面是黑的。

## 怎么跑

Flutter 在 `~/development/flutter`，没进 PATH：

```bash
export PATH="$HOME/development/flutter/bin:$PATH"
cd ~/Desktop/yuanjing_app
flutter run -d "iPhone 16 Pro"
```

调着色器（不用开模拟器）：

```bash
cd packages/yuanjing_engine
swiftc -O tool/preview/main.swift ios/yuanjing_engine/Sources/yuanjing_engine/StagePipeline.swift -o /tmp/render_preview
/tmp/render_preview shaders/stage.metal /tmp 0:0.5:0   # 财富，进度一半；输出 /tmp/f00.png
./tool/embed_shaders.sh
```

## 安卓

目前只有 iOS 实现，安卓上舞台显示黑底。着色器的写法是通用的，移植到安卓用 Vulkan 或 OpenGL ES 重写渲染壳即可，场景代码大部分能照搬；有模型的 3D 在安卓上用 Filament。
