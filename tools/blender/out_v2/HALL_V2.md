# 大殿 v2（面阔九间的重檐庑殿大殿）交接说明

2026-11-19。只做了 Blender 这一侧，**没有动 `unity/` 下任何文件**。下面的数字照着改 Unity 里的摆放、碰撞、寻路。
数字有两套坐标，表里都写清是哪一套：

- **本地**：大殿模型自己的坐标（Blender 里的 x 向右、y 往北、z 向上，原点在台基地面中心）。
- **世界**：Unity 的 (x, z)。大殿模型放在 `HallAt = (0, 0, 27.1)`，所以 世界 x = 本地 x，**世界 z = 27.1 + 本地 y**，高度不变。

## 13. 没做完的、我拿不准的（实话）

- **没进过 Unity。** 所有判断都来自 Blender 预览图：游戏里的着色器、贴图（tile、brick、lacquer 这些三向贴图在大面积的墙和柱子上平铺的效果）、殿内的暖光、俯视镜头下的比例，都没看过。
- **性能没测。** 大殿从 40 万涨到 55.7 万个三角形，其中殿里（`in_`）16.7 万；屋顶瓦 13.6 万。上檐的筒瓦已经省到每块 4 个三角形（没有瓦唇的端面），凑到屋檐底下往上看能看出来。真机帧率要你那边测；还嫌重的话，最省事的是把 `hall()` 里上檐 `a.roof(…)` 的 `course` 加大、下檐 `tile_segs` 改成 2。
- **地面贴图 8192 × 8192**（原来 4096）：显存是原来的四倍，老机器上可能要在导入设置里限到 4096（那样密度是 1.8 × 2.1 厘米，比以前差）。
- 岛的形状是「大方块接小椭圆」，腰上两个凹角比较硬，没有专门修饰；北边地块上除了两座土丘是空的草地，**树、石灯笼、草、花、小动物的地盘都要 Unity 那边重新撒**（老的殿后松竹的位置现在在台基底下）。
- 南半边岸线：z ≤ 3 完全不变；z 3 … 4.5 的东西两头往外鼓了最多 1.5 米（接缝要抹圆）。钟亭 (14.4, 6.6) 没动，但它东北边现在是陆地。
- 室内上层墙面的高窗是不会亮的米色窗纸（`in_toon`），没用 `glow`：不确定 Unity 那边 `in_` 部件里的发光怎么处理，就没加新的部件名。夜里从殿里看，高窗是暗的。
- 扇面墙正面只做了墙裙、金线框和顶上一道流云，中间是素红墙（等佛像和背光来挡）。如果佛像的背光比金线框（每间宽约 5.6、高到 10.4）小很多，红墙会显空。
- 须弥坛 `altar_dais`、供桌这些陈设是按老殿的大小做的，我没动 `hall_props.py`；§7 的位置和大小只是建议，没有摆进去看过。
- 柱础的莲瓣是每瓣八个面的简化雕法（一根柱子的柱础一百多个三角形），一米以内凑近看是一圈圆润的瓣，但没有老殿那种一瓣一瓣独立的厚度。门墙上窗间的六根柱子和所有嵌墙柱没有莲瓣和金箍（省面）。
- 上层檐下、殿后的斗拱是省面的简化款（一攒一百来个三角形），只有正面下檐和殿里的是细的。四个角的角科只是一攒斜着放的普通斗拱。
- 台阶只有正面一处，没有做两侧和殿后的踏跺；也没有做御路石、抱鼓石。
- 匾上是「大雄寶殿」、楹联是「慈雲廣被 / 慧日長明」，照老殿的没改。
- 预览里看到的几处小瑕疵没修：开着的门扇最里面那一扇（B）是素板，从殿里贴近门框斜着看能看到；下檐四角的角脊梢头翘得不算高。
