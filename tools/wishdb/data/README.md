# 愿望回应素材

每个 .txt 是一个分类（文件名就是分类：wealth 财富、career 事业学业、looks 外貌、health 健康、mood 情绪、life 生活、pet 宠物）。

格式：

    @意图编号 名字 | 关键词1 关键词2 !排除词 ...
    ~ anxious
    - 核心回应句：直接回应这个愿望
    > 行动句：接在核心句后面，一个具体的小行动或一个信念
    ? 一条用户可能写的愿望（只用来测匹配准不准，不参与匹配）

一条完整回应 = 开场（分类 × 情绪，segments.txt）+ 核心句 + 行动句 + 收尾（时段，segments.txt）。
核心句和行动句会随机两两搭配，所以**任意一条核心句接任意一条行动句都要读得通**。

## 每个意图的要求

- 核心句（`- `）至少 15 句，行动句（`> `）至少 6 句，测试愿望（`? `）至少 4 条；`.blank` 不用写测试愿望。
- `~ 情绪` 可选：这个意图默认的语气（calm 平常、eager 迫切、anxious 担心、heavy 沉重），用户的用词看不出情绪时用它。
- 每个分类必须有三个特殊意图：
  - `xx.general`：这个分类的兜底，什么具体意图都没对上时用；
  - `xx.short`：两三个字的抽象愿望（比如财富的「暴富」「发财」，外貌的「变美」）；
  - `xx.blank`：用户没写出具体内容（只写了「你」「啊」「123」之类）。要温暖地接住，不能假装听懂了。

## 句子的要求（会预录成语音）

- 每句 6～42 个字（不算标点）。
- 不写人名，不写「他」「她」（不知道用户说的是谁），用「你」「你爱的人」「那个人」「它」。
- 积极、温暖、具体，给人力量；不说空话套话，不吓人，不说教。
- 不承诺一定实现，不给医疗、投资、法律建议，不评判任何人。
- 负面或报复的愿望（希望谁倒霉、消失、遭报应）不顺着说，接住背后的委屈，把注意力转回到用户自己身上。

## 关键词

- 至少两个字（一个英文单词算两个字），越长越具体，权重越高。
- 以 `!` 开头的是排除词：愿望里出现它，就不算这个意图。
- 只写真正指向这个意图的说法；「希望」「顺利」「一定」这种到处都有的词不要写。

检查格式：`python3 build.py --check 分类`；生成回应库：`python3 build.py`。
